# Backend

The Python API of the application, built with FastAPI and Pydantic.

**Current state:** a minimal application with a health endpoint and its tests.
No product feature is implemented yet, and no environment variable is needed.

## Setup

Requires Python 3.11 or later. From this `backend/` folder:

```bash
# Create a virtual environment (macOS/Linux: python3 -m venv .venv)
py -3 -m venv .venv

# Activate it
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Windows Git Bash:   source .venv/Scripts/activate
# macOS/Linux:        source .venv/bin/activate

# Install the application and test dependencies
pip install -r requirements-dev.txt
```

If PowerShell refuses to run the activation script, skip activation and prefix
the commands with the environment's Python, for example
`.venv\Scripts\python -m pytest`.

## Run

```bash
uvicorn app.main:app --reload
```

The API listens on http://127.0.0.1:8000. Check it with
http://127.0.0.1:8000/api/health, which returns `{"status":"ok"}`. The
interactive documentation generated by FastAPI is at http://127.0.0.1:8000/docs.

## Test

```bash
pytest
```

## Structure

| Path | Content |
| --- | --- |
| `app/main.py` | FastAPI application and routes |
| `tests/` | Tests, run with pytest |
| `requirements.txt` | Runtime dependencies, pinned |
| `requirements-dev.txt` | Runtime plus test dependencies |
| `pyproject.toml` | pytest configuration |

All routes start with `/api`, so the frontend development server can forward
them to this API.

## Dependencies

`requirements.txt` pins every runtime package so that all team members install
the same versions. To add a dependency, install it in the virtual environment,
check that the tests still pass, then regenerate the pinned list from a clean
environment with `pip freeze`. Add packages when the feature that needs them is
implemented (for example pdfplumber and python-pptx with extraction).

## Planned responsibilities

- FastAPI endpoints and Pydantic request/response contracts.
- PPTX and PDF extraction with page or slide identifiers.
- Claude API calls and validation of structured responses.
- Study-sheet persistence, edit history or original AI versions, and the subject library in SQLite.
- Flashcard and quiz generation, plus scoring based on the agreed contract.

Organize modules as those responsibilities are implemented. Define schemas and
stub responses before integrating extraction or live AI calls.

Keep API credentials on the server. Local uploads, exports and databases are
ignored by Git. Reusable prompt text belongs in the root prompts/ directory.
