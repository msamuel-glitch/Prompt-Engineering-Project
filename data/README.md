# Development and evaluation data

The brief calls for 6–10 real courses in PDF and PPTX across several subjects.
Store local course files and generated outputs under data/local/, which is
ignored by Git. Create that directory when collecting samples.

Choose samples that cover typical courses, long courses and scanned PDFs. Record
observations about extraction quality, source references, summary coverage and
two-page print fit when the pipeline is ready.

Small synthetic fixtures may be added alongside the tests that use them. Only
commit materials the team has permission to share. Do not commit private course
files, API keys or local databases.
